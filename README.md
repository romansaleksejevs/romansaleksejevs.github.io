# Romans Aleksejevs Portfolio

## Files
- `index.html` — website content
- `styles.css` — design and responsive layout
- `script.js` — mobile navigation and reveal animation

## Before publishing
1. Replace `YOUR.EMAIL@example.com` in `index.html`.
2. Replace `https://www.linkedin.com/in/YOUR-LINKEDIN/`.
3. Put your CV PDF in the same folder and name it:
   `Romans_Aleksejevs_CV.pdf`
4. Review company names and dates if you want them shown publicly.

## Easy publishing options
- GitHub Pages
- Cloudflare Pages
- Netlify
- Vercel

The site is static and requires no backend.
